# Homework — Build React APP

A self-promotional Single Page Application (SPA) built with React and Vite, featuring an editorial Swiss graphic layout and zero-dependency modern CSS.

🔗 **Live Demo:** [https://abylau2.github.io/react-homework-build/](https://abylau2.github.io/react-homework-build/)  
📦 **Repository:** [https://github.com/abylau2/react-homework-build](https://github.com/abylau2/react-homework-build)

## 📋 Coursework Requirements Checklist

- [x] **Single Page Application (SPA)** built with React 19 and Vite
- [x] **Personal Name & Image:** Editorial typography featuring *Abylau* and Swiss vector artwork (`FIG. 01`)
- [x] **About Me Section:** Background, engineering focus, and structured developer metadata
- [x] **Contact Information:** Safe public contacts (GitHub, Instagram, Email, Planet Earth) — strictly no phone number or home address
- [x] **Modular React Architecture:** Exceeds the 3-component requirement with 7 dedicated components:
  1. `Header.jsx`
  2. `Hero.jsx`
  3. `About.jsx`
  4. `Projects.jsx`
  5. `Skills.jsx`
  6. `Contact.jsx`
  7. `Footer.jsx`
- [x] **Polished CSS Styling:** Custom Swiss editorial aesthetic, fluid typography (`clamp()`), and responsive design
- [x] **GitHub Pages Deployment:** Automated deployment via `gh-pages`

## 🚀 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/abylau2/react-homework-build.git
cd react-homework-build

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```
