A personal editorial single-page portfolio application built for the university assignment **“Build React APP”**.

## 📋 Homework Requirements Checklist

| Requirement | Implementation Details | Status |
| :--- | :--- | :---: |
| **React Single Page Application** | Built with Vite + React 18, zero backend dependencies, fast static build. | ✅ |
| **Personal Identity** | **ABYLAU** — Focused on **Cybersecurity / SOC Analysis** & automation. | ✅ |
| **Profile Photo / Avatar** | Local high-res character profile avatar integrated in the Character Dossier card (`FIG. 01`). | ✅ |
| **About Me Section** | Explains background in defensive security, interest in SOC analyst workflows, automation, and frontend exploration. | ✅ |
| **Personal Interests** | Dedicated editorial section featuring 4 genuine interests: **Rock Climbing**, **History**, **Manga & Anime**, and **Evolutionary Biology**. | ✅ |
| **Safe Contact Information** | Public contact links provided (GitHub, Instagram, Email) with clipboard copy buttons. Sensitive data (phone number, home address) omitted in accordance with academic privacy rules. | ✅ |
| **Modular React Components (≥ 3)** | 7 modular components: `Header`, `Hero`, `About`, `Focus`, `Interests`, `Contact`, `Footer`. | ✅ |
| **Polished CSS Styling** | Swiss editorial design system, typography-driven, warm paper palette, zero generic AI slop. | ✅ |
| **Responsive Design** | Custom breakpoints tested for 1440px (desktop), 1024px (laptop), 768px (tablet), and 390px (mobile). | ✅ |
| **Deployable to GitHub Pages** | Configured with `base: "/react-homework-build/"` in `vite.config.js` and automated `gh-pages` deployment. | ✅ |

## 🛠 Tech Stack

- **React 18** (Components, State, Hooks)
- **Vite** (Next-generation frontend tooling)
- **CSS3** (Custom properties, grid, flexbox, clamp fluid typography)
- **gh-pages** (Automated GitHub Pages deployment)

---

## 🚀 Quickstart & Commands

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle for GitHub Pages
npm run build

# Deploy to GitHub Pages (gh-pages branch)
npm run deploy
```
